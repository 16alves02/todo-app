# ✅ Todo App

A lightweight task manager built with **HTML, CSS and JavaScript**, focused on clean UI, browser storage and responsive interaction.

## 🌐 Live Demo

[Open Todo App](https://todo-app-three-beta-56.vercel.app)

## ✨ Features

- Add, complete and delete tasks
- All / Active / Completed filters
- Persistent data with `localStorage`
- Responsive layout
- Dynamic current date
- Empty-state feedback

## 🛠️ Tech Stack

HTML5 · CSS3 · JavaScript · Font Awesome

## 🚀 Run locally

Clone the repository and open `index.html` in a browser. No build step is required.

```bash
git clone https://github.com/16alves02/todo-app.git
cd todo-app
```
